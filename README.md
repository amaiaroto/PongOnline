# Pong Online
___
## Description
Pong with online play featuring two players connecting to the device running the server.
> (can be more than two players (as in controlling the same paddle as of 8/11/2026))

___
### Usage
* "client.py": python .\client.py \[address to connect to\] \[port\] \[side 'L' or 'R' (case-sensitive)\]
* "server.py": python .\server.py \[port\]
